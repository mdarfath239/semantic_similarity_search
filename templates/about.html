About This Project

Architecture, model details, and design decisions.

Project Overview

Semantic Similarity Search is an NLP-powered document retrieval system that understands the meaning of a user's query rather than relying on exact keyword matching.

The system embeds both the query and each indexed document as dense numerical vectors using a pre-trained Word2Vec model, then ranks documents by their cosine similarity to the query vector.

How It Works
  1. Preprocessing — The query is lowercased, URLs/emails/digits are removed, and it is tokenised with NLTK's wordpunct_tokenize. English stopwords are removed (negations preserved).
  2. Embedding — Each token is looked up in the Word2Vec vocabulary. The token vectors are averaged into a single 100-dimensional query vector.
  3. Similarity search — Cosine similarity is computed between the query vector and all 18 227 pre-computed document vectors.
  4. Ranking — Documents are sorted by similarity score (descending) and the top N results are returned.

Limitations
  • Queries containing words absent from the Word2Vec vocabulary return no results.
  • The model is trained only on the 20 Newsgroups corpus — out-of-domain queries may produce low-quality results.
  • Averaging word vectors loses word-order information.
  • Cosine similarity is not a probability; a high score does not guarantee relevance.
  • The application is a portfolio demonstration and is not hardened for public production deployment.
Model Details
  • Algorithm Word2Vec (CBOW / Skip-gram)
  • Embedding dimensions 100
  • Similarity metric Cosine Similarity
  • Dataset 20 Newsgroups
  • Total indexed documents 18 227
  • Library Gensim
  • Training environment Google Colab
